LEEME - INSTALACION DE LA TIENDA (Nexbit POS web)
=================================================
(v2 - WooCommerce + licencias automaticas por correo)

La carpeta "tienda" recibe los pedidos pagados de tu tienda WooCommerce,
genera la licencia Nexbit POS y la envia al cliente por correo.

------------------------------------------------------------
PASO 1 - Base de datos (cPanel)
------------------------------------------------------------
- cPanel > "Bases de datos MySQL" > crear BD:  nexbit_tienda
- Crear usuario BD (ej: nexbit_tienda_user) con contrasena fuerte.
- Asignar el usuario a la BD con "TODOS los privilegios".
- Las tablas se crean solas la primera vez que se usa.

------------------------------------------------------------
PASO 2 - Subir los archivos (cPanel)
------------------------------------------------------------
- cPanel > Administrador de archivos (File Manager).
- Ve a public_html > crea la carpeta "tienda".
- Sube ahi el contenido de web/store del proyecto:
  woo-webhook.php, store-funciones.php, lib_*.php, store-config.example.php,
  admin.php, index.php, pagar.php, webhook.php, resultado.php, simular.php.
- Renombra store-config.example.php a store-config.php.

Opcional (recomendado): PHPMailer para envio con SMTP.
- Descarga https://github.com/PHPMailer/PHPMailer (Code > Download ZIP)
- Descomprime y sube la carpeta a public_html/tienda/PHPMailer/
  (la tienda lo usa automaticamente; si no, usa SMTP nativo o mail()).

------------------------------------------------------------
PASO 3 - WooCommerce: crear el webhook
------------------------------------------------------------
En tu tienda WooCommerce:
- WooCommerce > Ajustes > Avanzado > Webhooks > Anadir webhook:
      Nombre:           Nexbit POS licencias
      Estado:           Activo
      Topic:            Order updated (pedido actualizado)
      URL de entrega:   https://TUDOMINIO.cl/tienda/woo-webhook.php
      Secret de entrega: (palabra clave fuerte, la misma que en store-config.php)
- Guarda. Woo genera un pedido de ejemplo; "Enviar datos de prueba"
  dispara una entrega de prueba (el pedido de ejemplo no tiene tus
  productos: el webhook respondera "ningun producto del pedido es un
  plan", es lo normal en esa prueba).

En la tienda/store-config.php:
      'WOO_WEBHOOK_SECRET' => 'la misma palabra clave del webhook',
      'WOO_PRODUCTOS' => [
          123 => ['multi', 4, 10],   // ID del producto Woo "Plan Multi" -> [plan, cajas, usuarios]
          124 => ['basic', 1, 1],
      ],
  (el ID del producto lo ves en WooCommerce > Productos (columna ID);
   solo se procesan pedidos que incluyan productos de este mapa)

------------------------------------------------------------
PASO 4 - Correo (cPanel)
------------------------------------------------------------
- cPanel > "Cuentas de correo" > crea licencias@TUDOMINIO.cl
- En store-config.php:
      'MAIL_FROM' => 'licencias@TUDOMINIO.cl',
      'SMTP_HOST' => 'mail.tudominio.cl',
      'SMTP_PORT' => 465,          (587 + STARTTLS si tu hosting lo exige)
      'SMTP_USER' => 'licencias@TUDOMINIO.cl',
      'SMTP_PASS' => 'la contrasena del correo',
- Si el correo cae en Spam, revisa SPF/DKIM en tu cPanel.

------------------------------------------------------------
PASO 5 - Probar
------------------------------------------------------------
- Prueba real: compra el producto en tu tienda con el gateway en modo
  prueba (o un pedido pequeno) y deja el pedido en "processing"/"completado".
- El webhook procesa solo pedidos pagados (processing o completed) y
  genera + envia la licencia UNA sola vez (repeticiones no duplican).
- Alternativa SIN Woo: simular.php?id=N marca un pedido como pagado
  (solo con HABILITAR_SIMULADOR=true en store-config.php).
- Resultados en: https://TUDOMINIO.cl/tienda/admin.php (clave ADMIN_CLAVE).
  Ahi puedes reenviar la licencia de un pedido ya pagado.

------------------------------------------------------------
PASO 6 - Produccion
------------------------------------------------------------
- 'HABILITAR_SIMULADOR' => false
- 'ADMIN_CLAVE' => una clave larga

------------------------------------------------------------
FLUJO ALTERNATIVO - Tienda propia con Flow (sin WooCommerce)
------------------------------------------------------------
Si alguna vez quieres vender desde una pagina tuya sin WooCommerce:
- index.php (planes) + pagar.php (pago Flow) + webhook.php + resultado.php
- Crea comercio en https://sandbox.flow.cl (pruebas) o www.flow.cl (real),
  pon apiKey/secretKey en store-config.php y SANDBOX true/false.

------------------------------------------------------------
SEGURIDAD - importante
------------------------------------------------------------
- store-config.php contiene claves (Woo, SMTP, Flow): NO lo subas a GitHub
  (ya esta en .gitignore).
- El secreto LICENSE_SECRET viaja en el codigo de todos los clientes
  (api/index.php). La tienda lo usa para generar licencias. Si quieres
  firma asimetrica (mas segura), avisame y lo migramos.
