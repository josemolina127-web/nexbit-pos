Preguntas frecuentes

Todo lo que debes saber antes de comprar

¿Necesito internet para usar Next Byte?

Solo lo necesitas para instalar o actualizar el programa. Una vez instalado, la aplicación funciona completamente offline.

¿Es un sistema en la nube?

No. Next Byte es un programa local que se instala en tu PC con Windows; tus datos quedan en tu propio equipo.

¿Puedo probarlo antes de comprar?

Sí, existe una versión demo instalable en modo de prueba para que la conozcas antes de decidir.

¿Qué pasa si mi licencia expira?

Te avisamos con anticipación. Al renovar, todo sigue funcionando igual y tu información queda intacta.

¿Cuántas cajas soporta el plan Multi-Cajas?

Hasta 4 equipos pueden trabajar al mismo tiempo compartiendo la misma base de datos en tu red local.

¿Cómo hago un respaldo de mis datos?

En el plan Pro y superiores, puedes respaldar tu base de datos con un solo botón. En el plan Básica, se hace copiando el archivo de datos manualmente.
